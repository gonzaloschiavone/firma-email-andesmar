# Firma Email — Andesmar Cargas

Generador de firma corporativa para correo electrónico. Permite a los empleados de Andesmar Cargas crear su firma personalizada lista para pegar en Gmail, Outlook y otros clientes de correo.

## Uso

1. Abrí el archivo `index.html` en tu navegador.
2. Completá tus datos (nombre, cargo, teléfono, dirección).
3. Hacé clic en **"Copiar Firma"**.
4. Pegá la firma en Gmail (Ajustes → Firma → Ctrl+V).

## Compatibilidad

- Gmail
- Outlook
- Apple Mail
- Yahoo Mail

## Tecnologías

- HTML5
- Tailwind CSS (CDN)
- Google Fonts: Montserrat, Plus Jakarta Sans
- JavaScript vanilla
